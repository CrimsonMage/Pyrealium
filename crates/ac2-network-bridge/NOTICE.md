# Native protocol bridge

This adapter is licensed AGPL-3.0-only. It uses ac2-net and ac2-core from CrimsonMage/AC2_Rusted, pinned to bcf67b4b9ac3ee9eb429d68ba6766cfce47c5a25. Preserve the upstream LICENSE and NOTICE.md when redistributing the bridge and provide its corresponding source, including those dependency crates. The dependency runs in this executable; the process that drives it (the server's Python tests) communicates through anonymous stdin/stdout pipes.

Source: https://github.com/CrimsonMage/AC2_Rusted/tree/bcf67b4b9ac3ee9eb429d68ba6766cfce47c5a25

No original game DATs or original client executables are included.
